One environment variable. Zero code changes. Full governance.
This is the core architecture. Govrix Scout is a transparent HTTP proxy. Your agents don't need any code changes — you just point their base URL at the proxy. The proxy captures every request and response, runs them through the policy engine and PII scanner, stores them in TimescaleDB with a tamper-evident Merkle hash chain, and makes everything visible through a 15-page governance dashboard. It supports OpenAI, Anthropic, MCP (Model Context Protocol), and Agent-to-Agent protocols.

How We Solve It

🔒 Tamper-Evident Audit Trail
SHA-256 Merkle chain links every event cryptographically. Modifying any event invalidates the entire chain. Regulators can verify integrity independently.
🛡 PII Detection & Masking
Real-time scanning for emails, SSNs, credit cards, phone numbers, API keys. PII values are never stored — only type and location are logged.
⚡ Kill Switch + Circuit Breakers
Manual kill, emergency kill-all, plus automatic circuit breakers for loop detection, cost spikes, and risk score breaches. Stops rogue agents in real-time.
💰 Budget Enforcement
Per-agent token and cost limits. Progressive enforcement: warn at 80%, throttle at 90%, hard block at 100%. Resets daily with countdown timers.
📊 Risk Scoring & Anomaly Detection
Real-time risk gauge (0-100) per agent. Detects off-hours usage, token volume spikes, new tools, unusual provider switching, cost escalation.
🎬 Session Recording
Full conversation replay with SHA-256 integrity hash. Verify that recordings haven't been tampered with. Audit-ready transcripts.
⚙ Policy Engine
YAML-configurable rules with hot-reload. Actions: block, redact, alert, allow. Evaluated synchronously with zero I/O on the hot path. Fail-open by default.
⚖ Compliance Frameworks
SOC 2 Type II, EU AI Act, HIPAA, NIST 800-53 — built-in control matrices with pass/fail/partial status tracking and export for auditors.
Each of these features maps to a real governance requirement. The Merkle chain is inspired by blockchain — each event's hash depends on the previous one, making the audit trail tamper-evident. PII detection runs in real-time on every request/response. We never store actual PII — just the type (e.g., "email detected at messages[0].content"). The kill switch has both manual controls and automatic circuit breakers — if an agent starts looping or burning through budget, it gets stopped automatically. The policy engine is evaluated synchronously but with zero database I/O — so it adds less than 1ms of latency to the hot path.

Industry Readiness

Performance <1ms p50 latency, <5ms p99.
Built on hyper directly — not a framework. The proxy never becomes the bottleneck.
Scale TimescaleDB hypertables for time-series data. Bounded 10K event channel with fire-and-forget persistence. No backpressure on the hot path.
Reliability Fail-open by design. If the policy engine panics, if the database is down — the proxy still forwards traffic. Governance never blocks your agents.
Protocol Coverage OpenAI, Anthropic, MCP, A2A. Streaming support. Protocol auto-detection. One proxy covers the entire agent ecosystem.
Compliance 4 frameworks: SOC 2 Type II, EU AI Act, HIPAA, NIST 800-53. Built-in control matrices, not third-party integrations.
Open Source Full transparency. Community-driven. Enterprise tier for mTLS, SSO, and advanced session recording. Sustainable model.
This isn't a prototype. The proxy is built in Rust on hyper — the same HTTP library that powers Cloudflare Workers. The fail-open design is critical for enterprise adoption. Nobody will deploy a governance proxy that could take down their AI agents. We support every major AI protocol — OpenAI, Anthropic, MCP for tool use, and even Agent-to-Agent delegation tracking. The compliance frameworks aren't checkboxes — they're real control matrices with evidence tracking and export capabilities.
